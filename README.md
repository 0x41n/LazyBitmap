## LazyBitmap
- ブラウザで動く貧弱なビットマップフォントエディタ
- とにかくラクしてフォントを作りたい
- [ここ](https://0x41n.github.io/LazyBitmap)で動きます

## できること
- プロジェクトの保存 / 読込
- BDF / TTF / WOFFの書出
  - ビットマップ埋込
  - コードページのフラグ立て
- 基本的なフォントの情報の編集
- パーツによる文字の組立
- プロジェクトファイルの結合(Merge)

## できないこと
- BDF / TTFの読込
- カーニング、合字などの高度な編集
- ほかにもいろいろ

## 操作説明(雑)
### 左側
- フォント情報の編集 / 確認
### 中央
- ビットマップ編集
  - ドットの打込
  - 上下左右のシフト移動
  - 左右/上下反転
  - 文字固有の送り幅設定
- 文字入力によるプレビュー
- 文字編集ではパーツの削除
- パーツ編集では名前の編集
### 右側
- 文字追加
  - Unicodeもしくは文字入力で追加
  - 文字一覧からクリック、もしくは文字入力による計算で編集画面へ
  - 「⧉」でコピー、「×」で削除
- パーツ追加
  - 「+」ボタンでパーツ追加
  - 文字編集中はパーツ一覧からクリックでパーツ追加
  - パーツ編集中はクリックで編集パーツ切替
  - 「✎」でパーツ編集、「×」で削除
